Welcome

This map is designed to be a collaborative accessibilty map for Oakland University.

You can click on the pin points on the map to read about an area an it's accessibilty.

  • Colors correspond to the difficulty, red for hard to access and green for easy to access.
  • Purple points mark where events are currently happening. Be mindful that an event happening could lead to more congestion and traffic.

You can right click on the map to add a point yourself.

  • Please add anything you think is helpful to campus accessibility.
  • You could add points marking if doors are currently not working or if roads are currently icey.
  • If you make a point about accessibility, consider adding tips on how to avoid that roadblock, if you know any. For example if it is hard to access a building through a certain door, maybe suggest another one.
